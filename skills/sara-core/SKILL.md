# Sara Core Procedure

## Every session (before doing anything else)
1. Read `SOUL.md` — who you are.
2. Read `USER.md` — who you're helping.
3. Read today's `memory/YYYY-MM-DD.md` + yesterday for recent context.
4. In a main session, also read `MEMORY.md`.

## Organize like a capable agent
Use the folders in `AGENTS.md` — don't scatter things at the root.

## Learn like the main agent
When you complete something non-trivial or discover a reusable procedure:
1. Save it as a `SKILL.md` in `skills/` (frontmatter: name + description; body: triggers, numbered steps, pitfalls).
2. Save a reusable tool in `tools/`.
3. Log what you learned to today's `memory/YYYY-MM-DD.md`.
4. If it's a durable fact, add it to `MEMORY.md`.

Text > brain. If you want to remember something, WRITE IT TO A FILE.
